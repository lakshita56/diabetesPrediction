# Diabetes Prediction App

A machine learning web application that predicts the likelihood of diabetes based on medical attributes.

## Features
- Binary classification using Logistic Regression
- Interactive web interface built with React
- Real-time prediction from user input
- Exploratory Data Analysis on diabetes dataset

## Tech Stack
Python, Pandas, Scikit-Learn, Matplotlib, Seaborn, React

## Live Demo
https://diabetes-prediction-silk.vercel.app

## Dataset
Kaggle Pima Indians Diabetes Dataset

## Model Accuracy
75.32%
